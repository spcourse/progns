# Installatie

## 1. Installeer de nieuwste Python met uv

Ga naar [deze tutorial](https://www.proglab.nl/welkom/install/uv/nl/) om Python te installeren.

Vergeet niet het check-scriptje aan het eind van de tutorial te gebruiken.

## 2. Installeer de benodigde packages

Om je te helpen controleren of wat je programmeert ook daadwerkelijk in overeenstemming is met de opdracht, hebben wij een programma geschreven genaamd **checkpy**. Dit programma kun je installeren door in de terminal het volgende commando uit te voeren:

	uv pip install checkpy

Dit kan even duren, en je zult wat tekst over je scherm zien gaan. Daarna is checkpy geïnstalleerd. Behalve checkpy hebben we ook tests nodig om jouw uitwerkingen te testen. Deze tests kun je downloaden door éénmalig het volgende commando in de terminal te voeren:

	uv run checkpy -d uva/progns

## 3. Installeer Visual Studio code

Dit pakket kun je downloaden op de website van [Microsoft](https://code.visualstudio.com/). Ook hier geldt dat je het bestand nog moet uitvoeren en installeren. Je hoeft niks aan te passen aan de installatie-opties. Heb je een Mac? Dan wordt het programma in je Downloads-map gezet. Je kunt het vanuit daar gewoon opstarten.
